# Prévias · Estúdio Basileus 👑

Páginas de demonstração criadas pelo Estúdio Basileus, publicadas pelo GitHub Pages para serem mostradas a cada negócio.

Cada pasta é uma página independente. As páginas são demonstrações: não são sites oficiais dos negócios e ficam fora dos buscadores.

Este repositório recebe só os arquivos prontos de cada página. O código-fonte, o briefing e as decisões de cada site ficam no repositório da fábrica.
